# Legacy Java Swing Sürümü

Deponun [8 Ocak 2022 tarihli commit'i](https://github.com/omermuktar/K-t-phaneTakip/tree/84d0b623e85087ae395a8ccb73dac611b8084c63),
üzerinde çalıştığım Java 8, Swing, JDBC ve MariaDB/MySQL tabanlı ilk masaüstü sürümünü arşivler.

İlk sürüm, Akshat Agarwal'ın MIT lisanslı
[Library-Management](https://github.com/git-akshat/Library-Management) projesinin Türkçe arayüz
uyarlamasını temel alır. Kaynak projenin lisansı ve README dosyası tarihsel ZIP içinde
korunmuştur. Lisansın tam metni
[üçüncü taraf bildirimleri](../THIRD_PARTY_NOTICES.md) dosyasına da eklenmiştir.

Eski ZIP; sabit yerel veritabanı parolası ve güncel olmayan JDBC sürücüleri nedeniyle yeni
sürümden kaldırıldı. Tarihsel commit değişmeden durur. Aktif proje, depo kökünde 2026 yılında
yeniden tasarladığım Spring Boot uygulamasıdır.
